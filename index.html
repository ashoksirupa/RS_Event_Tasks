Wedding Task Planner

Connect to your Google Sheet — one-time setup, about 2 minutes.
  1. Go to sheets.new and name the sheet Wedding Task Planner Data.
  2. Open Extensions → Apps Script.
  3. Delete everything in the editor and paste in AppsScript.gs. Save.
  4. Click Deploy → New deployment, type Web app.
  5. Set Execute as: Me and Who has access: Anyone, then Deploy. Authorize it (Advanced → Go to project — it's your own script).
  6. Copy the Web app URL (ends in /exec) and paste it below.

Tip: after it connects, use Share → Add to Home Screen (iPhone) or ⋮ → Add to Home screen / Install app (Android, desktop Chrome). The connection is saved in that shortcut.
